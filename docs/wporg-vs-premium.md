# WordPress.org vs Premium

Toplist Block ships as **two mutually exclusive plugins**:

- **Toplist Block Lite** — generated by `scripts/build-lite.php`, distributed on WordPress.org
- **Toplist Block** (Pro) — canonical source in `toplist-block/`, sold via portal

Lite must comply with [WordPress.org plugin guidelines](https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/) (especially guideline 5: no locked/trialware features). Premium features are **removed** from the lite build, not disabled in the UI.

See [free-vs-premium.md](./free-vs-premium.md) for the full feature manifest (ticket 102).
