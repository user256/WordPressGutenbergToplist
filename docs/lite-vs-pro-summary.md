# Toplist Block Lite vs Pro

## Toplist Block Lite

Toplist Block Lite is the streamlined WordPress.org version of the plugin. It gives editors a Gutenberg block for building ranked lists directly inside posts and pages, without requiring a license, remote services, or extra admin workflows.

### Core Lite functionality

- Gutenberg toplist block with front-end rendering
- Pipe-delimited row editing directly inside the block
- Inspector controls for theme, defaults, and field visibility
- Global settings for CSS, display toggles, and default labels
- Upgrade-safe content model so existing blocks continue working if you later move to Pro

### Best fit for

- Sites creating a small number of toplists manually
- Editors who want a simple block workflow inside Gutenberg
- WordPress.org users who need a usable free version without operational overhead

## Toplist Block Pro

Toplist Block Pro is the full operational version for publishers who manage toplists as a reusable content system rather than as one-off blocks. It adds centralised toplist management, import/export workflows, automation, and commercial features for scaling list publishing.

### Top Pro functionality

- Reusable saved toplist library with `toplist_list` entries
- Linked live lists so one source can update multiple posts
- CSV and JSON import/export for individual lists and bulk workflows
- Spreadsheet-style and row-builder admin editing tools
- REST/API sync for remote toplist population
- Geo-targeted rows and regional variants
- Outbound click tracking and optional link obfuscation
- ItemList JSON-LD schema output
- License validation and over-the-air updates

### Best fit for

- Publishers running many toplists across multiple posts
- Teams who need faster content operations and bulk editing
- Commercial sites that want tracking, schema, geo variants, and managed updates
